Rejoindre un ménage MapleBook

Votre code d'invitation :

  1. Installez MapleBook à partir de Google Play.
  2. Ouvrez l'onglet Ménage (ou Paramètres → Comment vous utilisez MapleBook → Ménage et personnel).
  3. Créez un compte ou connectez-vous.
  4. Sous « Se joindre à un ménage », entrez le code d'invitation.

Votre budget personnel reste privé. Seul ce que vous ajoutez au ménage est partagé.
